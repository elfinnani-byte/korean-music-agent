# ZEROBASEONE

분류: 2020년대 음악 그룹, 2023년 결성된 음악 그룹, 5인조 음악 그룹, K-pop 음악 그룹, 대한민국의 댄스 음악 그룹, 대한민국의 보이 밴드, 대한민국의 아이돌 그룹, 대한민국의 음악 그룹, 대한민국의 팝 음악 그룹, 아이돌 그룹, 웨이크원 소속, 제로베이스원, 한국어 음악 그룹

ZEROBASEONE(제로베이스원)는 웨이크원 소속으로 2023년 7월 10일에 데뷔한 대한민국의 5인조 보이 그룹이다.


== 소개 ==
팀명 제로베이스원 ZEROBASEONE은 제로(0)에서 시작해 원(1)으로 탄생하는 아홉 멤버의 찬란한 시작을 의미한다. 미완성인 0부터 1까지 ZEROBASEONE이 걷게 될 자유로운 여정을 팬들과 함께 하겠다는 멤버들의 다짐도 내포하고 있다. 팀명은 ZB1으로 축약해 표현할 수 있다.리더는 성한빈이다.

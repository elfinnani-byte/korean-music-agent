# 다비치

분류: 2000년대 음악 그룹, 2008년 결성된 음악 그룹, 2010년대 음악 그룹, 2020년대 음악 그룹, K-pop 음악 그룹, 골든디스크 본상 수상 음악가, 골든디스크 신인상 수상 음악가, 다비치, 대한민국의 R&B 음악 그룹, 대한민국의 걸 그룹, 대한민국의 아이돌 그룹, 아이돌 그룹, 여성 듀오, 하이원 서울가요대상 본상 수상 음악가, 하이원 서울가요대상 신인상 수상 음악가, 한국어 음악 그룹

다비치(Davichi)는 대한민국의 여성 2인조 듀오 그룹이다. 2008년 2월 22일, 정규 1집《Amaranth》를 발매하며 성공적으로 데뷔했다.

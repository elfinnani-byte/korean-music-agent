# TWS (음악 그룹)

분류: 2020년대 음악 그룹, 2024년 결성된 음악 그룹, 6인조 음악 그룹, K-pop 음악 그룹, Mnet 아시안 뮤직 어워드 수상 음악가, 대한민국의 아이돌 그룹, 아이돌 그룹, 플레디스 소속, 한국어 음악 그룹

TWS(투어스)는 2024년 1월 22일에 데뷔한 플레디스 엔터테인먼트 소속의 대한민국의 보이그룹이다. 그룹명은 TWENTY FOUR SEVEN WITH US의 약자이다.
